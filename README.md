**Этот проект является моей попыткой реализовать fullstack сайт на c# aspnet на основе MVC паттерна с сервисами и DI контейнером**.

**Суть сайта**: биржа для выдуманных предметов, все невсерьез, пользователи могут создавать мнимые предметы, могут выставлять мнимые ордеры, управлять ими, выкупать чужие ордеры, за выдуманную мнимую валюту.

**Это пет проект!!!**
Не более чем проект на моем пути изучения веб разработки и c# .net core 8+ версии в целом)
