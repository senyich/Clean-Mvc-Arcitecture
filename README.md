**Этот проект является моей попыткой реализовать fullstack сайт на c# aspnet на основе MVC паттерна на основе сервисов и DI контейнера**.

**Суть сайта**: биржа для выдуманных аукционов на выдуманные предметы, все не всерьез, пользователи могут создавать мнимые предметы, могут выставлять мнимые лоты, управлять ими, выкупать чужие лоты, за выдуманную мнимую валюту.

**Это пет проект!!!**
Не более чем проект на моем пути изучения веб разработки и c# .net core 8+ версии в целом)
